# Migrating from v0.2 to v0.3

Version 0.3 is a pre-release architecture reset. It replaces palette-oriented
skins and Tailwind-dependent copied source with the Mlola Theme engine.

## Theme attributes

Use:

```html
<html data-theme="atelier" data-mode="light">
```

v0.2 used `data-skin` for the look and `data-theme` for light/dark. In v0.3 the
look is `data-theme` and light/dark is `data-mode`, so a v0.2
`data-theme="dark"` must become `data-mode="dark"`. This is the one rename that
silently changes meaning, so check every `data-theme` when migrating.

`data-skin` remains a compatibility alias for one release and is removed in
0.4.0. New code must not write both attributes. The full ledger, with removal
versions, lives in `packages/engine/src/deprecations.mjs` and is enforced by
`tests/deprecations.test.mjs`.

Canonical mappings:

- `mlola` → `atelier`
- `mono` → `machined`
- `mist` → `aerogel`
- `forest`, `ocean`, and `ember` → `nordic`

The legacy aliases preserve old installations; they do not represent distinct
v0.3 themes.

## CSS

Remove Tailwind and the old semantic bridge from the consumer setup. Import the
Mlola engine entry generated by `mlola-ui init`.

Old utility classes applied directly to copied components are not guaranteed to
work. Prefer component props, semantic `ml-*` recipe classes, or a documented
consumer cascade layer.

Legacy shadcn-style custom properties such as `--background` and `--foreground`
remain aliases until 0.4.0. Migrate custom CSS to `--ml-*` semantic roles.

## CLI

Initialize a project once:

```bash
npx mlola-ui init
```

Then add source:

```bash
npx mlola-ui add button sheet
npx mlola-ui doctor
```

The CLI now reads a bundled registry snapshot, resolves source dependencies, and
uses targets from `mlola.config.json`. Blocks, pages, and templates are no longer
copied into `components/ui`; pages use the `pages` alias (`@/app/pages` by
default) and templates use `templates`.

## Component behavior

Overlay, collection, and composite widgets now share the Mlola behavior kernel.
Some incomplete v0.2 behavior is intentionally breaking:

- Sheet traps and restores focus.
- Modal and Sheet isolate background content.
- Tabs use roving focus and complete keyboard navigation.
- Collapsed Accordion content is removed from navigation.
- Select supports controlled and uncontrolled values.
- Error toasts use an assertive live region.

Test applications that relied on background focus, hidden accordion traversal,
or partial ARIA behavior must be updated.

## Motion and scene

Pointer kinetics are requestAnimationFrame-batched and stop while idle.
`prefers-reduced-motion` disables tilt, parallax, bounce, and decorative
stagger. Scene effects are optional and preserve a static rendering.

## Icons

Replace Lucide and duplicated inline SVGs with exports from
`@mlola-ui/icons`. Icon metaphors remain stable while optical expression can
follow the active theme.

## Verification

After migration:

```bash
npm run check
npx mlola-ui doctor
```

The doctor command reports missing engine imports, incompatible packages,
legacy theme attributes, modified generated files, and forbidden dependencies.
