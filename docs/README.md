## Foundations

The foundation documents define the derived scales, spring profiles, and
constraints used by the engine. The philosophy and methodology documents explain
the Mlola theme and its method. Generated token files are outputs, not
authoring surfaces.

## Package references

Each publishable package owns its API reference and build contract. Component,
block, and template specifications live beside their source and describe
anatomy, behavior, registry dependencies, and theme channels.
