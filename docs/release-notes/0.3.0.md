# Mlola UI 0.3.0

Mlola is a **framework-free design system with a machine-readable contract**.
A theme is a coherent transformation across eight expression channels, the
engine emits plain CSS and JSON with no runtime dependency, and every class and
attribute a renderer may use is generated from the stylesheet and audited — so a
model reading the contract cannot invent a class that does not exist.

This is a pre-release architecture reset. It is the first version published
under this name, and it is marked **pre-release** on npm.

## Install

```bash
npx mlola-ui init
npx mlola-ui add button sheet hero-split landing
npx mlola-ui doctor
```

```css
@import "@mlola-ui/engine";
```

```html
<html data-theme="atelier" data-mode="light">
  <button class="ml-button" data-variant="primary">Save</button>
</html>
```

Themes: `atelier`, `machined`, `aerogel`, `nordic`. Modes: `light`, `dark`.

## Highlights

- **Framework-free core.** The engine is plain CSS and JSON, behavior is a
  standard DOM module, and React is one supported consumption path. A browser
  test proves the runtime works from a bare static server, with no bundler.
- **A contract a model cannot misread.** `contract.json` lists every class and
  the `data-*` / `aria-*` attributes the CSS reacts to, and `agents.md` is
  generated from the same source. Both are checked in CI.
- **Four ordered layers.** Components → blocks → pages → templates, with the
  rule that a lower layer never imports a higher one and behavior is only ever
  owned by a component.
- **Measured accessibility.** An OKLCH-to-sRGB contrast gate enforces WCAG AA on
  every canonical palette, and reduced motion, forced colors, and a compact
  viewport are asserted in the browser suite.
- **Real kinetic physics.** The engine samples a damped oscillator into CSS
  `linear()` easings per theme, with a cubic-bezier fallback, and the
  pointer-driven spring integrator stops at rest.
- **Owned everything.** Icons, motion, scene, and behavior are Mlola packages.
  No Tailwind, clsx, Radix, Lucide, or external motion runtime is shipped.

## Packages

The open-source distribution is the components layer plus the runtime packages.
Blocks, pages, and templates are part of the commercial catalog and are not in
these tarballs.

| Package | What it is |
| --- | --- |
| `@mlola-ui/engine` | generated CSS, spring easings, and the machine-readable contract |
| `@mlola-ui/tokens` | stable CSS entry |
| `@mlola-ui/behavior` | framework-free interaction runtime and shared decisions |
| `@mlola-ui/motion` | kinetic primitives and the spring integrator |
| `@mlola-ui/scene` | optional spatial presentation |
| `@mlola-ui/icons` | Mlola Glyph DNA icon catalog |
| `@mlola-ui/registry` | validated metadata and source snapshot |
| `mlola-ui` | the source-copy CLI |

## Migrating from 0.2

`data-theme` changed meaning: in 0.2 it selected light/dark, and in 0.3 it
selects the theme. The switch moved to `data-mode`.

```diff
-<html data-skin="mlola" data-theme="dark">
+<html data-theme="atelier" data-mode="dark">
```

`data-skin` and the shadcn custom-property aliases still work and are removed in
0.4.0; the ledger lives in `packages/engine/src/deprecations.mjs`. Tailwind
utilities applied to copied components are not supported. See
[the migration guide](https://github.com/mlolahq/mlola-ui/blob/main/docs/migration/v0.2-to-v0.3.md).

## Breaking changes

- Vocabulary: theme (`data-theme`, `--ml-theme-*`) and mode (`data-mode`),
  replacing taste/temperament and the old `data-theme` switch.
- `@mlola-ui/core` was removed; no component imported it.
- The static utility bridge and its generated stylesheet were removed.
- `packages/recipes` was removed; it only re-exported the engine.

## Verification

- `npm run check` — engine and registry drift, dependency firewall, recipe and
  scale audits, contract audit, performance budgets, TypeScript, unit tests.
- `npm run test:e2e` — 145 browser tests: render coverage for all 45 registry
  items, the mode and state matrix, the keyboard map of every behavior, the
  schema endpoints, and the temperament visual corpus.
- `npm run check:pack` — the real `npm pack` for all eight packages, checking
  contents, license, and public access.

## Known limits

- Automated browser coverage is Chromium. Firefox and Safari are a per-release
  manual pass, recorded in
  [the accessibility checklist](https://github.com/mlolahq/mlola-ui/blob/main/docs/accessibility-checklist.md).
- The library is 27 components, 12 blocks, 5 pages, and 1 template. It is a
  design-system engine first, not a breadth-first component kit.
